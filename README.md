# Автоматизация разбора файлов


[![hexlet-check](https://github.com/artemu78/test-program-please-ignore-ai-automation-project-439/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/artemu78/test-program-please-ignore-ai-automation-project-439/actions)

Напишите консольную программу на JavaScript, которая разбирает папку с документами
компании: определяет тип каждого файла, находит дубликаты, отделяет полезные документы
от посторонних и собирает реестр. Отдельная команда сводит выгрузки контактов из разных
источников в одну таблицу — приводит колонки к единому виду, нормализует телефоны
и email, убирает повторы.

Учебный проект Хекслета: https://ru.hexlet.io/programs/test-program-please-ignore-ai-automation

## Использование

Проверить JavaScript с помощью ESLint:

```bash
npm run lint
```

Команда `files` выводит число файлов непосредственно в указанной папке,
сводку по типам (табличные, текстовые и непарсимые) и статусам (документы,
ручной разбор и посторонние файлы), количество копий и групп, а также создаёт
`registry.csv` в папке из `--out` (по умолчанию `./out`). Реестр содержит одну
строку на файл; для CSV и JSON у документов дополнительно указываются число
строк данных и названия колонок. Копии определяются по SHA-256 содержимого или
по имени после нормализации регистра, суффикса `(1)` и слова «копия». В
`report.json` команды `contacts` у основной копии `duplicateOf` равен `null`,
а у остальных файлов группы содержит путь к ней.
Тип определяется по расширению и сигнатуре файла; распознанная сигнатура
важнее расширения. Содержимое вложенных папок пока не учитывается. Команда
`contacts` создаёт общий отчёт в текстовом и JSON-форматах:

```bash
node bin/file-automation.js files ./company-files --out ./out
node bin/file-automation.js contacts ./company-files --out ./out
```

Для `contacts` в `--out` появятся `report.txt` для чтения человеком и
`report.json` для дальнейшей обработки программами. Если `--out` не указан,
используется `./out`.

Показать справку:

```bash
node bin/file-automation.js --help
```
